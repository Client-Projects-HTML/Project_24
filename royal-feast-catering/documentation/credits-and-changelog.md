## v1.0.0 — Initial release
- 16 public pages including two distinct home page styles (Classic & Premium/Signature Collection).
- 8-page Admin Portal (dashboard, enquiries, bookings, menu, gallery, testimonials, customers, settings).
- Full design system: CSS variables, responsive breakpoints, dark mode, RTL support.
