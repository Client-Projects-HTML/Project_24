# Page Structure

## Public site (16 pages)
| Page | File | Purpose |
|---|---|---|
| Home — Classic | `index.html` | Primary landing page: hero, services, menu preview, why-us, events, testimonials, stats, CTA |
| Home — Premium | `home-2.html` | "Signature Collection" landing page: same brand, premium tone, pricing-first layout, process timeline |
| About | `about.html` | Story, mission/vision, chef team, kitchen standards, awards timeline |
| Services | `services.html` | All 6 catering services + 4-step booking process |
| Service Details | `service-details.html` | Deep dive on Wedding Catering: included items, food options, equipment/staff, FAQs, related services |
| Menu | `menu.html` | Tabbed menu: Vegetarian / Non-Vegetarian / Live Counters / Desserts |
| Menu Details | `menu-details.html` | Single-dish detail: ingredients, spice level, serving size, allergens |
| Gallery | `gallery.html` | Filterable photo grid with lightbox (weddings, birthdays, corporate, festivals, outdoor) |
| Events | `events.html` | Event types catered, each with guest capacity and sample menu |
| Pricing | `pricing.html` | Silver/Gold/Platinum packages, add-ons, pricing FAQs |
| Testimonials | `testimonials.html` | Rating stats, review grid, video testimonial cards |
| Enquiry | `enquiry.html` | Full quote-request form with live guest-count & budget helpers |
| FAQ | `faq.html` | Two-column accordion: Booking & Planning / Menu & Service |
| Contact | `contact.html` | Contact cards, contact form, map placeholder, working hours, social |
| Blog | `blog.html` | 6-post article grid |
| Coming Soon | `coming-soon.html` | Countdown timer + email capture |
| 404 | `404.html` | Custom error page with return-home / browse-menu CTAs |

## Admin portal (8 pages, `/admin/`)
No public navbar/footer — sidebar + topbar shell instead, per dashboard design guidelines.
| Page | File | Purpose |
|---|---|---|
| Dashboard Overview | `admin/index.html` | KPI cards, weekly enquiry chart, monthly snapshot, recent enquiries table |
| Quote Enquiries | `admin/enquiries.html` | Full enquiry list with status filter |
| Event Bookings | `admin/bookings.html` | Upcoming confirmed/pending events |
| Menu Management | `admin/menu.html` | Dish list with type/price/status |
| Gallery & Media | `admin/gallery.html` | Photo management grid |
| Testimonials | `admin/testimonials.html` | Review moderation table |
| Customers | `admin/customers.html` | Customer directory |
| Settings | `admin/settings.html` | Business profile fields + preference toggles |
